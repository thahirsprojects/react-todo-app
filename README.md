# React Todo App

A simple and interactive **Todo List application** built with **React**. This app allows users to add, complete, and delete tasks in a sleek and responsive interface.

## Demo

[Live Demo Link](https://todoappbythahir.web.app/)


## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Add tasks by clicking the **Add** button
- Responsive and modern UI

## Technologies Used

- **React** – Frontend library for building UI components
- **React Icons** – For iconography
- **Tailwind CSS** – Utility-first CSS framework for styling
- **JavaScript / JSX** – Main programming language

## Installation

1. Clone the repository:

```bash
git clone https://github.com/thahirsprojects/react-todo-app.git
cd react-todo-app
```

2. Install dependencies:
```bash
npm i
```

3. Start the development server:
```bash
npm run dev
```
